# Аналитика

/get_stats: уникальные объявления из очереди доставки, Минск, одна комната, до $2000,
последние 30 дней. Медиана рассчитывается стандартной библиотекой.
Исторический ads.csv автоматически не импортируется. Полный экспорт исходных данных:
`python -m src.service.manage export > ads-inbox.jsonl` с production DATA_DIR.
Подробнее: [OPERATIONS.md](OPERATIONS.md).
